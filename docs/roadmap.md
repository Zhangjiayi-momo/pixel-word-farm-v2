# 产品与 AI 演进路线

## 第一阶段：稳定互动课堂
- 完成三阶段教学流程。
- 完成词库上传和格式校验。
- 完成教师主控、学生受限操作。
- 完成多色笔、荧光笔和同步批注。
- 完成学生默写提交与教师批改。

## 第二阶段：课堂体验增强
- 用 WebSocket 替换轮询，降低多人操作的延迟。
- 增加文字批注、单笔撤销、橡皮擦和批注历史。
- 增加学生连麦、跟读打卡和发音评分。
- 增加课程结束报告、错词本和下一课复习队列。
- 增加教师账号、学生账号和房间密码。

## 第三阶段：AI 助记
- 教师上传词表后，调用 GPT 生成词形切分和谐音草稿。
- AI 给出派生词、常见搭配、易混词和高考例句。
- AI 标记“谐音是否贴近真实读音”“是否会干扰拼写”。
- 所有 AI 内容必须进入教师审核区，确认后写入正式词库。
- API Key 只能保存在服务器环境变量中，不能下发到浏览器。

## 第四阶段：个性化复习
- 根据学生默写答案识别具体错因：漏字母、换顺序、发音混淆、词义混淆。
- 自动生成下一节课的错词队列。
- 对每个学生生成不同的助记版本和复现间隔。
- 课后生成课堂总结，包括跟读参与度、错词分布和掌握趋势。

## 第五阶段：Codex 工作流
- 让 Codex 读取教师上传的图片或表格，批量整理词条。
- 让 Codex 检查重复单词、缺失字段、词性错误和短语格式。
- 让 Codex 根据课堂反馈修改前端、增加题型和自动测试。
- 建立内容版本记录，任何 AI 修改都能回滚。

## 数据与隐私原则
- 不把学生姓名、答题内容和课堂记录发送给第三方，除非取得监护人和用户明确同意。
- 进入正式云端前，先完成数据脱敏、访问控制和数据删除机制。
- AI 只生成教学草稿，不直接自动给学生评分或定性。
